5. 按新曲线重建全相位双臂冲突图，完整名义几何与等待位姿 **5403 个采样**全部通过，再执行动力学。冻结输入与主场景 SHA 在发布和冷加载时再次检查。

## 场景中的问题

左塔上的临时连接已定位桥面，但尚不能独立承担桥面载荷，A 臂在桥下持续扶持。右侧永久塔的上层块 K1 和锁桥砖 K2 存放在左侧料区，设计上需要 A 供料；B 负责支撑工具与后续装配。A 如果一直扶着桥面，就无法拿到这些砖。

B 可以放入一个带配重底座的 C 形支撑架，确认它接替载荷后让 A 离开。A 取 K1、K2，经共享暂存区交给 B；B 从侧面装入 K1，再安装 K2，使永久承载结构闭合。最后要卸载支撑、将支撑运回工具位，并完成前挡板收口。

支撑位置会影响可选顺序。桥腹内部的位置可以承载，但前挡板闭合后，侧墙、后墙和挡板可能把支撑围住。靠前的位置保留外侧抽出通道。规划器应比较这些选择，而不是把“放进去以后结构暂时不倒”当作任务完成。

“只有 A 能取料”目前是工作站布置的设计约束：两臂基座位于左右两侧，K1、K2 料位到 B 侧较远。尚未完成所有抓取姿态、关节限位和碰撞条件下的 IK 可达性验证，不能把平面距离估算当成不可达证明。

正式规划器会在有限候选、IK 初值、采样时间和重试次数内检查资格；日志中的失败表示本次有界搜索未找到合格解，不是目标整体不可达或不存在可行路径的证明。A 专属供料限制同时属于当前任务模型的显式输入。

初始桥面自重在左侧连接处产生约 `0.45 × 9.81 × 0.26 = 1.148 N·m` 力矩，超过设计中的 `0.35 N·m` 临时连接限值。这是场景中“持续扶持有必要”的名义依据；实际连接及支撑仍需建模和验证。

在 `8 N` 插装工况下，同时计入动态版 `0.14 kg` 的 K2 自重，忽略临时连接和已接触永久塔可分担的载荷，支撑反力的保守平衡估计为下式。两个候选统一采用较短的 `x = 0.06` 支撑力臂计算载荷要求；外侧虽然已移到 `x = 0.08`，仍沿用这个保守要求。

```text
R × (0.06 - (-0.22))
  = 0.45 × 9.81 × (0.04 - (-0.22))
    + (8 + 0.14 × 9.81) × (0.24 - (-0.22))
R ≈ 19.498 N
采用 1.5 倍设计系数时，所需承载能力至少约 29.248 N。
```

此公式与正式编译器的候选载荷筛选一致；历史纯离散基线保留原先未计入新版 K2 自重的假设，不作为动态版的承载验收依据。这只是指定载荷下的准静态筛选。配重抗倾覆、接触压力分布、摩擦、工具抓取、结构变形、连接强度、插装冲击和实际卸载过程都不能由这一条公式替代。支撑架属于带回缩机构的假设工具，尚未完成实物机械设计验证。

## 如何接入 APEX-MR

[APEX-MR 原文](https://arxiv.org/html/2503.15836v2) 的主线是分配任务及抓取/支撑方式、生成顺序参考运动、构造多模态时间计划图并依照事件执行。本场景沿用这一接口方向，下列模块已共同完成上述运行的实际验收。

| 层次 | scene3 需要表达的内容 | 当前状态 |
|---|---|---|
| 任务与状态 | 已装部件、机械臂持物、支撑提供者、支撑位置、挡板状态、工具是否归仓 | `apex/scene.py` 和 `compile.py`；另保留离散基线 |
| ILP 或时序任务规划 | 分配安装/供料动作，选择支撑位置及占用区间，安排拆除时点 | `apex/allocation.py` 的 ILP 与几何失败反馈；本轮选择外侧支撑、先拆撑后关挡板 |
| 运动规划 | 含支撑工具和变化装配几何的 IK、抓取、侧向插入、撤离和双臂避碰 | `apex/motion.py` 与 Lua 后端的真实 RRT-Connect 查询 |
| 多模态 TPG | 同臂顺序、共享区域冲突、载荷转移和永久承载验证的事件边 | `apex/tpg.py` 生成路径片段及 Type-1/Type-2 依赖；`geometry.py` 检查名义执行 |
| 执行与验收 | 动态伺服、实际仿真载荷转移、卸载、拆除及结果日志 | `controller.lua / runtime.py` 与独立 `validation.py`；本轮完整实际验收通过 |

执行器与验收器检查以下事件约束：

```text
放置支撑 → 验证载荷转移 → A 解除扶持 → A 取专属料区积木
永久连接完成 → 验证独立承载 → 支撑鞋回缩卸载 → 抽出支撑 → 工具归仓
选择内侧支撑时：抽出支撑 → 关闭前挡板
```

“支撑到达指定位置”不能直接触发 A 松手；“K2 到达目标位姿”不能直接允许拆撑。需要相应承载观测与稳定判据。支撑仍受载时禁止直接水平拖出；物体已经出桥下也不等于支撑已归仓。

## 实验与比较

建议比较全程机械臂扶持、固定临时支撑、只检查放置时稳定性的支撑选择，以及考虑装配过程与取出顺序的完整方法。机械臂扶持基线应允许合理的换撑、交接和暂存动作；否则容易把人为限制误写成方法收益。

正式实验记录完成率、实际完工时间、机械臂支撑占用时间、额外操作次数、最大连接载荷、支撑连续性和工具回收成功率。规划耗时与执行耗时分别记录。候选筛选、IK 可达、无碰路径、动力学通过与多次重复试验成功率也应分开报告。

当前已完成一次完整动力学仿真与独立验收。工作站参数、单次规划结果、实际完整执行和多次重复实验的性能结论仍需分别记录；尚未完成各基线的对照与多次重复试验，不声称某个实测成功率或速度提升。
